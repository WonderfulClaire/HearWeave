# Simulated smart-glasses scene

`simulated_glasses_scene.npz` is a deterministic, synthetic four-channel scene generated by `scripts/generate_assets.py`.

Contents:

- `sample_rate_hz`: 16,000
- `target_azimuth_deg`: target direction used by the simulator
- `microphone_positions_m`: 4 × 3 smart-glasses microphone coordinates
- `clean_reference`: synthetic speech-like reference probe
- `microphone_signals`: delayed probe plus independent white noise, shape 4 × samples

The sample contains no recorded speech, biometric data, or third-party content. It is released under the repository's MIT license and is intended for smoke tests and tutorials—not algorithm benchmarking.
